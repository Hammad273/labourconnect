# LabourConnect backend — Stage 1

This folder contains the initial Flask + MySQL backend scaffold.

## Requirements

- Python 3.10 or newer
- MySQL Server running locally
- Git

## 1. Create and activate a virtual environment (Windows)

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

If PowerShell activation is blocked, use Command Prompt:

```bat
.venv\Scripts\activate.bat
```

## 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

## 3. Create the database

Open MySQL Workbench, open `schema.sql`, and execute the complete script.

## 4. Configure credentials

Copy `.env.example` to a new file named `.env` in this folder.
Set DB_PASSWORD to your own local MySQL password. Never commit `.env`.

## 5. Run the API

From this folder, run:

```bash
python app.py
```

Open these local endpoints:

- http://127.0.0.1:5000/
- http://127.0.0.1:5000/api/health
- http://127.0.0.1:5000/api/db-health

The database health endpoint succeeds only when MySQL is running and the
database and credentials have been configured correctly.

## Security notes

- This is a development scaffold, not a production deployment.
- Do not use real worker or contractor personal information yet.
- Password hashes must be generated by the application; never store plaintext passwords.
- The sample agreement records are not legally authenticated signatures.
- Before public launch, add authentication, authorization, CSRF/CORS protections
  as appropriate, validation, rate limiting, audit history, migrations, and
  production secret management.
